# Responsive

## Visão geral

Os utilitários `.fs-stack`, `.fs-cluster`, `.fs-stack-md-row` e
`.fs-table-responsive` compõem layouts que se adaptam ao espaço disponível.
O comportamento usa propriedades lógicas e funciona com `dir="rtl"`.

## Estados

Em telas estreitas, grupos responsivos ocupam toda a largura e tabelas passam
a permitir rolagem horizontal. O layout continua funcional em zoom de 200% e
em orientação portrait ou landscape.

## A11y

O componente não altera a ordem semântica do conteúdo. Para tabelas largas,
mantenha uma legenda (`caption`) e forneça uma indicação textual quando a
rolagem horizontal for necessária.
