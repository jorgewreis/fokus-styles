# List group

## Visão geral

`.fs-list-group` e `.fs-list-group-item` compõem listas de navegação ou seleção.

## Estados

Use `.is-active` para o item atual e elementos `a` ou `button` para itens interativos.

## A11y

Escolha uma lista semântica e forneça nome ao grupo quando ele representar uma região.
