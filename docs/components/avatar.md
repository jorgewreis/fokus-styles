# Avatar

## Visão geral

Use `.fs-avatar` para representar uma pessoa, equipe ou entidade com imagem ou iniciais.

## Estados

Combine `.fs-avatar-sm`, `.fs-avatar-lg` e `.fs-avatar-square` conforme o contexto.

## A11y

Imagens devem ter `alt` descritivo; iniciais devem ter um nome acessível com `aria-label`.
