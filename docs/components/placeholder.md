# Placeholder

## Visão geral

`.fs-placeholder` representa conteúdo ainda carregando e é visualmente distinto de Skeleton.

## Estados

Use `.fs-placeholder-glow`, `.fs-placeholder-wave` ou `.fs-placeholder-btn` conforme o formato.

## A11y

Anuncie carregamento com `aria-busy="true"` no contêiner e uma região live quando necessário.
